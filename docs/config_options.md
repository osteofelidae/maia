# Configuration options
* `module_id_to_port_map`: pairs of module ids and module ids
* `default_instruction_priority`: default instruction priority, if not set
* `instruction_priorities`: pairs of instruction types and priority levels (smaller is higher priority)
* `loop_timeout`: timeout duration for module sockets, queue checkers, etc. in seconds
* `log_file_location`: location of log file. $PROJECTDIR refers to root dir of project
* `log_file_save_interval`: interval to save log file, in seconds
